# 关于客服问答系统的安装与使用

## 如何安装系统
首先在命令行中执行 pip install -r requirements.txt 安装全部依赖。系统支持 Python 3.11 及以上版本。安装完成后，需要把项目根目录下的 .env.example 复制一份并改名为 .env，在里面填入 DEEPSEEK_API_KEY 才能调用大模型回答问题。

## 数据与配置文件存放在哪里
.env 文件位于 01_mvp 目录下，它保存了 API 密钥和大模型型号等敏感信息，不应提交到代码仓库。原始文档存放在 04_文档源 目录，评估集存放在 03_测评集 目录，二次优化产物存放在 02_优化 目录。

## 如何启动界面
在 01_mvp 目录执行 streamlit run app.py 命令。启动成功后浏览器会自动打开本地地址 http://localhost:8501，在左侧导航栏可以切换到智能问答或者评测与优化页面。

## 为什么答案要带引用出处
系统要求大模型只依据检索到的资料作答，并在用到某条资料时在句末标注 [编号]。这样做可以追溯答案来源，降低幻觉的风险，同时便于用户核实信息的真实性。

## 大模型接口配置
系统通过 OpenAI 兼容接口调用 DeepSeek 服务，默认地址为 https://api.deepseek.com。模型名在 .env 中通过 LLM_MODEL 配置，默认使用 deepseek-v4-flash，若该型号不可用，可改为 deepseek-chat。

## 知识库没有相关内容时怎么办
当检索到的文本块相似度都低于设定阈值时，系统不会强行作答，而是返回提示：抱歉，知识库中没有找到相关资料，建议改述或联系人工，避免编造答案。
