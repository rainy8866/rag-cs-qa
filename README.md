# RAG 客服问答平台（自评可量化）

一个**带完整评测与二次优化闭环的 RAG 客服问答系统**：上传文档建知识库 → 对话带引用出处回答 → 用 `召回率 / 引用准确率 / 坏例` 三大指标自我证明效果 → 一键做参数寻优（TopK / MIN_SCORE / Rerank）并把对比沉淀成报告。

> 定位：这是一份"面向 AI 产品经理"的工程化项目——核心不只是"能答"，更是**怎么证明"答得准"**。因此整套系统围绕"数据→评测→优化→留痕"的设计，文档源 / 评估集 / 优化报告都可复现。

## 功能亮点

- **结构感知切块**：`# 标题 → 段落(空行) → 句子`，细粒度切块（CHUNK_MIN_SIZE），拒绝固定字符硬切，让"一个块 = 一个知识点"。
- **检索**：bge-m3 本地向量化 + Chroma 余弦相似度，`MIN_SCORE` 阈值门控防幻觉，top-k 召回去重。
- **生成**：DeepSeek 注入检索片段生成带 `[n]` 引用的答案。
- **评测闭环**：`Recall@k`（检索层是否命中应引原文）/ `引用准确率`（引用是否真撑得起结论）/ `坏例分析`（recall_miss / citation_error / hallucination / empty_answer 四类归类，驱动二次优化）。
- **评测集工程**：LLM 自动生成问答对 + 手工补口语化 + 难例/边界例分层 + 语义去重（bge-m3 余弦） + 文档快照版本化，保证"改前 vs 改后"用同一份试卷对比。
- **二次优化**：网格搜索 `TOP_K(3/5/8) × MIN_SCORE(0.3/0.35/0.4) × Rerank(开/关)`，选召回率最优档，并输出优化前后对比报告。
- **多格式文档源**：Word/PDF/Excel/PPT → Markdown（markitdown）一键转码入库。

## 快速开始

```bash
cd 01_mvp
pip install -r requirements.txt
copy .env.example .env   # 填入 DEEPSEEK_API_KEY；若报模型不存在，LLM_MODEL 改 deepseek-chat
streamlit run app.py     # http://localhost:8501
```

进入「评测与优化」页，按：**重建知识库 → 生成评估集 → 检测召回率/引用准确率/坏例 → 一键优化 → 导出指标报告**。

汉化说明：`04_文档源` 已内置 16 份中文电商客服 FAQ（约 2.5 万字，入库约 255 块），克隆后即可直接跑通全流程。

## 评测指标

- **Recall@k**：检索层是否把"答案需要的那段原文"找出来（漏了就是 recall_miss）。
- **引用准确率**：答案里每条 `[n]` 引用是否真的支撑了对应结论（编造就是 citation_error / hallucination）。
- **坏例分析**：把答错的样本按根因分类，是"检索没召回 / 引用编造 / 答案为空"，直接指导下一步优化方向。

## 可选数据源

若不使用内置 FAQ，可将自有业务文档（md / docx / pdf / xlsx / pptx）放入 `04_文档源` 后重建知识库；需真实对话语料可参考公开的京东客服语料 JDDC 自行整理导入。
