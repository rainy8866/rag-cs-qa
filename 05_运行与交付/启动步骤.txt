【一】首次准备：填 API key（只需做一次）
--------------------------------
1. 进入目录：
   C:\Users\qzh-0\Desktop\rag-cs-qa\01_mvp

2. 把 .env.example 复制一份，命名为 .env
   （用记事本打开 .env.example，把内容另存为 .env 即可）

3. 用记事本打开 .env，填写：
   DEEPSEEK_API_KEY=你的key
   LLM_MODEL=deepseek-chat
   （已固定用 deepseek-chat；deepseek-v4-flash 仅特定场景人工排查时手动切换）

4. 保存关闭。

--------------------------------

--------------------------------
打开命令提示符，输入：

   cd C:\Users\qzh-0\Desktop\rag-cs-qa\01_mvp
   .\.venv\Scripts\python.exe -m streamlit run app.py

浏览器会自动打开，或手动访问：
   http://localhost:8501

【三】使用流程（推荐顺序）
--------------------------------
页面一「💬 智能问答」
  - 直接提问即可，答案带引用号 [1][2]，可点开看来源。

页面二「📊 评测与优化」——按这个顺序点：
  1. 「重建知识库」：把 04_文档源 里的文档向量化入库（首次必须）
  2. 「生成评估集」：自动生成测试题（会调用 DeepSeek）
  3. 「检测召回率」：跑出召回率数值
  4. 「检测引用准确率」：跑出引用准确率
  5. 「检测坏例」：列出答得不好的样本并归类
  6. 「一键优化」：自动尝试优化，产出改前/改后对比
  7. 「导出报告」：把指标存成报告文件

--------------------------------
【四】遇到问题怎么办
--------------------------------
1. 依赖没装？已经用清华镜像装好到 .venv 里，无需重装。
   如果以后换机器/重装，执行：
      cd C:\Users\qzh-0\Desktop\rag-cs-qa\01_mvp
      .\.venv\Scripts\python.exe -m pip install -r requirements.txt

2. 提示模型不存在？.env 里把 LLM_MODEL 改成 deepseek-chat。

3. 装包时网络报错？这台电脑的系统代理 127.0.0.1:7892 会干扰 pip。
   解决：临时关掉系统代理开关，或先执行：
      set HTTP_PROXY=
      set HTTPS_PROXY=
      set ALL_PROXY=
   再 pip install。（跑网页本身不受代理影响）

4. 首次建档/跑评估时，huggingface 的 symlink 警告可忽略，不影响功能。

5. 想换真实业务文档？把 04_文档源 里的文件换成你的手册/FAQ，
   重新点「重建知识库」即可，系统会自动重新入库。

--------------------------------
