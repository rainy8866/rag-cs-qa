# 演示录屏说明

录制一段约 3 分钟的演示，按下面顺序操作，最能体现项目价值。

## 建议流程
1. **0:00-0:30 开场**：一句话——"这是一个带可量化评测的 RAG 客服问答平台：既能上传文档建立知识库回答，又能用召回率/引用准确率/坏例证明自己答得准。"
2. **0:30-1:10 开头建档**：到「评测与优化」页点「重建知识库」，再到「生成评估集」。
3. **1:10-1:50 问一个带引用的问题**：到「智能问答」页提问，展示答案中的 `[1][2]` 角标，展开参考资料看原文出处。
4. **1:50-2:20 展示指标**：回评测页，依次点「检测召回率」「检测引用准确率」「检测坏例」，展示数字与柱状图。
5. **2:20-3:00 二次优化**：点「一键优化」，展示优化后 Recall 提升，以及「导出指标报告」，收尾强调"改前 vs 改后是同一份评估集对比"。
