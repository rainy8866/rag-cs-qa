# 参考资料与故障排查

## 文档源在哪里维护
项目默认使用的示例知识库是 LangChain 官方文档。你可以运行 04_文档源 目录下的 fetch_docs.py 自动下载，也可以直接把 04_文档源 里的离线样例当作用料。要把系统用在真实业务上，只需把 04_文档源 里的文件替换成你自己的产品手册或 FAQ，然后重新建立知识库即可，不用改任何代码。

## 首次运行会下载模型
嵌入模型使用本地的 BAAI/bge-m3，首次运行时需要从 HuggingFace 下载权重。如果国内下载较慢，可以在 .env 中设置 HF_ENDPOINT=https://hf-mirror.com 使用镜像加速。

## 模型名报错怎么办
如果调用大模型时报错提示模型不存在，请检查 01_mvp/.env 中的 LLM_MODEL 取值。默认填写的模型若不可用，请改为 deepseek-chat，这是 DeepSeek 官方稳定的通用对话模型。

## 重新建立知识库
当你更换了 04_文档源 里的文档后，需要在评测页面点击重建知识库按钮，系统会重新切块、向量化并写入向量库。更换文档源或改变切块方式都属于改变知识库的动作，按照规范必须新建一个版本快照，不能直接覆盖旧版本。
